# SQL Sales & Customer Analytics Project

## Project Overview

This project demonstrates the use of SQL for analyzing sales, product, customer, revenue, profit, and delivery data.

The analysis was performed using sales, products, and customers tables. SQL queries were developed to answer practical business questions and extract meaningful insights from transactional data.

## Objective

The objective of this project is to use SQL to:

* Retrieve and filter sales data
* Analyze orders and delivery status
* Calculate revenue, profit, and average order value
* Analyze sales by product, category, state, and month
* Identify top-performing products and customers
* Analyze repeat and inactive customers
* Perform customer lifetime value analysis
* Calculate month-over-month revenue growth
* Identify profitable and unprofitable products
* Apply advanced SQL techniques for business analysis

## Tools & Technologies

* SQL
* Oracle SQL
* SQL Developer
* Sales, Products & Customers datasets

### Customers Table

* State

## SQL Skills Demonstrated

### 1. Basic SQL Queries

* SELECT
* WHERE
* ORDER BY
* DISTINCT
* NULL handling

Examples include retrieving all orders and identifying delivered and undelivered orders.

### 2. Data Cleaning & Transformation

The project includes handling price values stored with currency symbols and commas using functions such as:

* REPLACE
* TO_NUMBER
* REGEXP_LIKE
* TO_CHAR

These transformations were used to convert text-based currency values into numeric values for analysis.

### 3. Aggregations

Used SQL aggregation functions including:

* COUNT
* SUM
* AVG
* GROUP BY
* HAVING

These were applied to calculate orders, revenue, profit, and customer activity.

### 4. Joins

Used INNER JOIN to combine information from:

* Sales
* Products
* Customers

This enabled analysis such as customer revenue, product revenue, category performance, and state-level sales.

### 5. Revenue & Profit Analysis

Calculated:

* Total revenue
* Revenue by category
* Revenue by state
* Monthly revenue
* Product revenue
* Product profit
* Profit percentage

Revenue was calculated using quantity and product unit price. Product-level profit was analyzed using the difference between unit price and unit cost.

### 6. Top-N Analysis

Identified:

* Top 10 products by revenue
* Top 10 customers by revenue
* Top 3 products within each category
* Top 5 customers within each state

Window functions such as RANK() were used for category- and state-level ranking.

### 7. Customer Analysis

Analyzed:

* Customers with more than 5 orders
* Repeat customers
* Customers who have not purchased recently
* Customer lifetime value

A 90-day period was used to identify customers whose most recent purchase was older than 90 days.

### 8. Time-Based Analysis

Performed monthly revenue analysis and calculated month-over-month revenue growth using:

* Common Table Expressions (CTEs)
* LAG()
* Date functions

### 9. Advanced SQL

The project demonstrates:

* CTEs
* Window functions
* RANK()
* LAG()
* CASE statements
* Nested subqueries
* Aggregate functions
* Conditional filtering using HAVING

### 10. Product Profitability Analysis

Products were classified based on profit percentage into categories such as:

* Highly Profitable
* Profitable
* Low Profit
* Loss

This classification was created using a CASE statement.
